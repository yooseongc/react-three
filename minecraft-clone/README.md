# Voxel Garden · 복셀 정원

React Three Fiber로 만든 작은 탐험·건축 정원입니다. PC 브라우저에서 숲을 걷고 나만의 집을 지을 수 있습니다.

**플레이:** [물빛 숲](https://yooseongc.github.io/react-three/?world=willow) · [작은 집 데모](https://yooseongc.github.io/react-three/?demo=build)

## 개발 계획과 진행 기록

[복셀 정원 로드맵](./ROADMAP.md)에서 마일스톤, 완료 기준, 검증 및 진행 내역을 관리합니다.

## Tech Stack

- Node.js 26.13.1 LTS / npm 11.20.0
- React / React DOM 19.3.1
- [react-three-fiber](https://github.com/pmndrs/react-three-fiber) - React renderer for Three.js
- [@react-three/drei](https://github.com/pmndrs/drei) - Useful helpers (Sky, etc.)
- [zustand](https://github.com/pmndrs/zustand) - State management

Three.js 0.187.0, R3F 9.8.2, Drei 10.7.9, Zustand 5.1.0을 사용합니다.
빌드는 Vite 8.3.8, 테스트는 Vitest 5.1.0 / jsdom 31.0.1입니다.
플레이어 충돌은 `src/game/world.js`의 고정 간격 AABB 계산으로 처리합니다.
사용하지 않는 Cannon 및 CRA 의존성은 M2.5에서 제거했습니다.

## Project Structure

```
src/
├── App.jsx             # Main app - Canvas, Sky, lighting
├── components/
│   ├── Chunk.jsx       # Exposed faces batched by chunk/material
│   ├── Cubes.jsx       # Chunk rendering and shared materials
│   ├── Decorations.jsx # Instanced decorative grass
│   ├── FPVControls.jsx # First-person view controls
│   ├── Ground.jsx      # Ground plane
│   ├── Hud.jsx         # HUD overlay
│   └── Player.jsx      # Player controller
├── hooks/              # Custom hooks
├── images/             # Texture images
├── game/               # Voxel index, meshing, collision, ray traversal, fixtures
└── textures.js         # Shared texture loader
```

## Getting Started

```bash
nvm install 26.13.1
nvm use 26.13.1
npm ci
npm start
```

개발 주소는 `http://127.0.0.1:5173/react-three/`입니다.
`.nvmrc`에 Node 버전을 기록했습니다. nvm-windows에서는 위처럼 버전을 명시합니다.
OpenSSL 호환 옵션은 더 이상 필요하지 않습니다.

## M1 조작과 저장

- **산책 시작 / 계속하기** 버튼으로 마우스를 잠급니다.
- **WASD** 이동, **Shift** 달리기, **Space** 점프, 마우스로 시점을 조절합니다.
- 이동은 실제 카메라의 수평 시선 방향을 기준으로 합니다. 위아래를 봐도 이동 속도는 같습니다.
- 오른쪽 미니맵은 북쪽(-Z) 고정이며 블록 배치, 현재 위치·시선 방향, 시작점과 X/Y/Z 좌표를 표시합니다. Y는 플레이어 발밑 높이입니다.
- **좌클릭** 블록 파괴, **우클릭** 블록 설치, **1–6** 현재 페이지 블록 선택입니다.
- **Q/E** 재료 페이지 전환, **휠** 전체 12종 재료 순환입니다.
- **F** 비행 전환, 비행 중 **Space** 상승 / **C** 하강입니다. 비행 중에도 블록을 통과할 수 없습니다.
- 조작 거리는 6칸이며 몸 안이나 같은 위치에 블록을 설치할 수 없습니다.
- **ESC** 또는 창 포커스 이탈 시 일시정지합니다. 재개하려면 버튼을 누릅니다.
- 변경 후 0.5초, 일시정지, 탭 숨김 및 페이지 종료 시 저장을 시도합니다.
- 저장 중에는 화면 오른쪽 위에 **저장 중…**, 성공하면 **저장됨**을 2.5초 표시합니다. 실패 안내는 유지되며 메뉴의 **지금 저장**으로 재시도할 수 있습니다.
- 저장 키는 `voxel-garden.world.v1`입니다. 이전 `world` 저장은 읽기만 하고 보존합니다.
- 현재 저장이 손상되면 원본을 `voxel-garden.world.v1.backup`에 보존한 뒤 연습 월드를 엽니다.
  백업이나 저장소 접근에 실패하면 저장을 비활성화하고 안내합니다.
- 플레이어 위치는 아직 저장하지 않으며 재접속 시 안전한 시작 위치로 이동합니다.
- 현재 월드는 100×100 평면, 건축 중심 좌표 범위는 X/Z ±49, Y 1–64입니다.
  지형 생성과 대규모 월드 최적화는 M2 이후 범위입니다.

## M2 청크 월드

- [청크 연습장](http://127.0.0.1:4173/react-three/?demo=chunks): 16,384블록 기반 플랫폼, 경계를 가로지르는 목재·유리 구조물, 인스턴싱 잔디 장식.
- [성능 측정 월드](http://127.0.0.1:4173/react-three/?demo=benchmark): 64×64×4 고정 월드. 저장하지 않으며 새로고침하면 초기화됩니다.
- 기본 주소는 기존 개인 월드를 그대로 사용합니다. 연습장만 별도 `voxel-garden.m2-demo.v1` 키에 저장합니다.
- 청크는 16×16×16 크기입니다. 내부 면을 제거하고 청크·재질별로 메시를 합칩니다.
- 편집한 청크와 면을 공유하는 경계 이웃만 다시 만들며, 제거한 지오메트리는 해제합니다.
- 충돌은 플레이어 주변의 점유 셀만 조회하고, 조준은 메시 삼각형 대신 격자를 따라 탐색합니다.
- 장식 잔디는 단일 InstancedMesh이며 충돌·파괴 대상이 아닙니다.
- 화면 성능 패널은 데모에서만 표시되며 드로콜에는 그림자 패스를 포함합니다.
- 저장 형식은 기존 v1을 유지합니다. 청크 인덱스는 불러올 때 재구성합니다.

## M5 월드와 설정

- 시작/ESC 메뉴의 **플레이·월드·설정** 탭을 사용합니다.
- **월드 → 새 숲의 시드 → 숲 열기**: 같은 시드는 이어 열고, 다른 시드는 새 숲을 생성합니다.
- **최근 월드 이어하기**는 마지막으로 플레이한 월드를 엽니다. 현재 플레이어 위치는 저장하지 않아 안전한 시작점에서 재개합니다.
- **현재 월드 내보내기**로 JSON 파일을 다운로드합니다. **월드 파일 가져오기**에서 내용을 확인하고 **새 복사본으로 가져오기**를 선택합니다.
- 파일은 최대 8MB / 15만 블록이며, 이 앱의 내보내기 형식과 이전 v1 블록 저장 형식을 지원합니다. 알 수 없는 재료·중복 좌표·범위 밖 블록·지원하지 않는 생성기 버전은 거부합니다.
- 가져온 숲은 원래 시드/수면을 유지하며, 원본과 별도 저장됩니다. 내보낸 파일에 브라우저 설정은 포함하지 않습니다.
- 마우스 감도·효과음·그림자·미니맵 설정은 브라우저에 유지됩니다.
- 저장 실패 시 월드 전환을 멈추고 파일 내보내기 또는 저장 없이 이동할 선택을 제공합니다.
- 저장은 서버 동기화가 아닌 현재 브라우저/사이트 주소의 localStorage입니다. 로컬 데모와 공개 사이트 간 이동은 파일 내보내기/가져오기를 사용하세요.
- 모바일 터치 조작, 수영/유체, 멀티플레이는 포함하지 않습니다.
- [M5 검증 기록](docs/M5-VALIDATION.md)

## 시드는 무엇인가요?

시드는 기본 풍경을 만드는 입력값입니다. 같은 시드는 같은 지형과 나무 배치를 만듭니다.
현재 생성기는 호수와 해변의 대략적인 위치는 고정하고, 시드에 따라 높이와 나무 분포를 바꿉니다.
내가 지은 집은 시드에 포함되지 않고 이 브라우저에 별도로 저장됩니다.
다른 사람이 같은 시드를 입력하면 같은 출발 풍경만 보며, 건축물까지 공유하려면 월드 파일을 내보내 전달해야 합니다.

## M6 정확한 건축과 복구

- 선택 재료의 반투명 미리보기와 설치 좌표가 표시됩니다. 초록은 설치 가능, 빨강은 불가이며 이유를 함께 표시합니다.
- Ctrl/Cmd+Z 실행 취소, Ctrl/Cmd+Shift+Z 또는 Ctrl+Y 다시 실행. ESC 메뉴 버튼으로도 사용할 수 있습니다.
- 설치·파괴의 최근 100개 기록을 현재 월드 세션에 보관합니다. 새로고침/월드 전환 시 기록은 초기화되지만 최종 블록 상태는 저장됩니다.
- 복원할 자리에 플레이어가 있으면 기록을 소모하지 않고 차단합니다. 이동한 뒤 다시 시도하세요.
- 성공한 새 편집은 다시 실행 기록을 지웁니다. 설치 불가나 빈 공간 파괴는 기록을 지우지 않습니다.
- [M6 검증과 화면](docs/M6-VALIDATION.md)

## M7 낮밤과 시간 고정

- 기본 오전 9시에서 시작하며 플레이 12분마다 하루가 흐릅니다. ESC 메뉴와 숨겨진 탭에서는 시간이 멈춥니다.
- 설정의 일출/한낮/노을/밤 버튼 또는 시간 슬라이더를 선택하면 해당 시간으로 고정됩니다. 자동 순환을 다시 체크하면 이어서 흐릅니다.
- 메뉴로 나올 때 현재 시각을 저장합니다. 시간 설정은 이 브라우저의 모든 월드에 공통이며 월드 공유 파일에는 포함되지 않습니다.
- 밤에도 건축할 수 있도록 달빛과 주변광을 유지합니다.
- [M7 검증과 화면](docs/M7-VALIDATION.md)

## M8 물결과 바람

- 얕은 수면에 잔물결이 흐르고 풀잎과 나뭇잎 표면이 바람에 움직입니다. 구름과 안개도 천천히 변합니다.
- 뾰족한 원뿔 장식은 여러 장의 풀잎으로 교체했습니다. 풀은 충돌/채집 대상이 아닌 장식입니다.
- 설정 → 풍경 움직임에서 켜고 끌 수 있습니다. 낮밤 시간 고정과 독립적이며 메뉴에서는 움직임이 멈춥니다.
- 수면을 막는 블록을 설치하면 해당 물 면이 사라집니다. 기존 건축·저장·실행 취소 규칙은 동일합니다.
- [검증 및 영상](docs/M8-VALIDATION.md)

## M9 날씨와 ASMR 배경음

- 날씨는 기본 자동이며 플레이 3–6분마다 맑음·흐림·비·안개·눈을 오갑니다. 메뉴에서는 멈추고, 개별 날씨를 선택하면 고정됩니다.
- 비·구름·조명·안개가 부드럽게 전환됩니다. 지붕은 비를 가리고 노출된 블록 윗면은 젖었다가 천천히 마릅니다.
- 안개는 먼 풍경을 감싸고 눈은 천천히 흩날립니다. 눈은 지붕 아래에서 가려지며 쌓이지 않습니다. 풍경 움직임 OFF는 비와 눈 입자를 숨깁니다.
- ASMR 배경음은 개별 효과음을 강조하지 않는 날씨별 사운드스케이프입니다. 효과음과 독립적으로 켜고 끄거나 음량을 조절합니다.
- 메뉴/포커스 해제에서는 배경음이 멈춥니다. 밤과 실내는 더 잔잔해집니다.
- 자동 날씨는 재접속하면 맑음에서 새 주기를 시작합니다. 날씨 모드와 배경음 설정은 이 브라우저의 모든 월드에 공통입니다.
- [검증과 데모](docs/M9-VALIDATION.md) · [음원 출처](public/audio/CREDITS.md)

작은 창에서도 캔버스는 뷰포트를 채우고, 핫바·미니맵은 크기를 줄여 화면 안에 유지합니다. 높이가 낮으면 보조 조작 안내를 줄이며 메뉴는 스크롤할 수 있습니다.

## M10 작은 생태계

시드 숲의 풀밭에는 토끼·여우·양, 연못과 바다에는 오리가 살아갑니다. 최대 토끼 8마리·오리 4마리·여우 2마리·양 2마리이며 가까이 가면 피하고 밤이나 비·눈에는 쉽니다. 시작점 왼쪽 풀밭과 북서쪽 연못부터 살펴보세요.

설정의 **작은 생태계 · 토끼·오리·여우·양**로 켜고 끌 수 있습니다. 메뉴에서는 움직임이 멈춥니다. 동물이 있는 곳에 건축하면 안전한 자리로 옮겨갑니다. 동물은 관찰용이며 플레이어를 막거나 블록을 변경하지 않습니다.

동물 위치는 저장하지 않으며 재접속하면 시드와 현재 지형에 맞춰 다시 배치합니다. 평면 연습 월드에는 생성하지 않습니다. [검증과 화면](docs/M10-VALIDATION.md)에 현재 범위를 기록했습니다.

## M11 1인칭 건축 UX

금색 테두리와 면은 현재 겨냥한 파괴 대상, 초록색 윤곽과 반투명 재료는 설치 예정 위치입니다. 설치할 수 없으면 빨간색과 × 표시, 이유를 보여줍니다. 허공에서는 조준 안내를 숨깁니다.

**마우스 가운데 버튼**으로 겨냥한 블록의 재료를 집어 선택할 수 있습니다. 재료가 있는 핫바 페이지로 자동 전환하며 월드의 블록은 바뀌지 않습니다. [검증과 화면](docs/M11-VALIDATION.md).
