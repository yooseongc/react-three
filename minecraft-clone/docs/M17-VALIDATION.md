# M17 시간·날씨 배경음악

- 제공된 4시간대 × 5날씨의 20곡을 실제 OGG 파일로 추가했다. [원본·CC0·변환 내역](MUSIC-CREDITS.md).
- 아침 05:00~10:00 / 낮 10:00~17:00 / 노을 17:00~20:00 / 밤 20:00~05:00. 자동 날씨와 시간 순환에도 동일하게 적용한다.
- 새 곡이 재생 가능해진 뒤 3초 교차 페이드. 현재 곡과 교체 곡만 미디어 요소로 스트리밍하며 이전 소스를 해제한다. 20곡 전체 디코딩 버퍼를 만들지 않는다.
- 실내 음량 65%, 독립 음량/켜기 설정, 메뉴·탭 숨김·창 이탈 즉시 음소거/일시정지. 뒤늦게 완료된 재생 요청이 메뉴에서 다시 소리를 켜지 않도록 처리했다.
- 실패 시 이전 곡 유지, 오류 안내와 다시 불러오기. 빠른 연속 전환에도 최대 2소스 제한 테스트.
- 모든 20개 파일을 실제 Chromium에서 로드/디코딩하여 readyState 4 및 길이 확인.
- 실제 설정 UI: 낮/맑음 → 노을/비. 전환 중 두 곡 gain 0.176 / 0.117, 완료 후 sunset_rain 0.2925 (실내), 이전 미디어 해제 확인.
- 프로덕션 preview의 `/react-three/assets/audio/…`에서 재생 확인. 메뉴 전환 시 currentTime 정지 및 paused=true 확인.
- 총 음원 29.69 MB. 첫 진입에 모두 다운로드하지 않지만 방문한 조합에 따라 브라우저 캐시는 늘어날 수 있다.
- 실제 Android/iOS 기기의 소리 재생은 사용자 요청에 따라 검증하지 않았다.

최종 전체 테스트 121개 및 프로덕션 빌드 통과. 실제 스피커 청취에 의한 주관적 음악 품질 평가는 하지 않았으며, 파일 디코딩·재생 진행·전환·gain·정지 상태를 확인했다.
