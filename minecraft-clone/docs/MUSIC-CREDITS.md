# 시간·날씨 음악 크레딧

20곡 모두 원본 페이지의 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 표시를 2026-11-14 확인했다. 제공된 곡 이름과 배정을 유지했다. 원본 URL·다운로드 URL·원본 SHA-256·사용 파일은 `src/game/musicTracks.json`에 기록했다.

- First Light Particles의 짧은 제공 URL은 404여서 같은 작품의 정상 node/182244 주소를 사용했다.
- 압축 파일은 루프 버전을 우선 사용했다. Iridescent Deep은 더 잔잔한 Alternate Loop, Safe Space는 loop 파일을 사용했다.
- 전체 곡을 OGG Vorbis q2, 44.1kHz 스테레오로 변환했다. 음량은 loudnorm I=-23, TP=-3, LRA=9, 시작 1.5초/끝 2초 페이드. 곡 길이는 자르지 않았다.
- 총 29.69 MB (28.31 MiB). 현재 곡만 요청하고 교체 중 최대 두 미디어 소스를 사용한다. 이전 M9 ASMR 파일은 사용하지 않는다.
