# 복셀 정원 로드맵

## 목표와 범위

GitHub Pages에서 바로 접속해 산책하고 작은 집을 지을 수 있는 싱글플레이 복셀 정원.
PC 브라우저와 키보드·마우스를 우선 지원한다. 따뜻한 풍경과 편안한 건축에 집중한다.
생존, 제작, 몬스터, 멀티플레이, 무한 월드, 낮밤 변화는 첫 출시 이후로 둔다.

## 구현 원칙

- M1부터 순차 진행하며 각 마일스톤 완료 시 진행 내역과 현재 상태 데모를 제공한다.
- 완료 보고에는 변경 사항, 검증 결과, 남은 제한 사항, 데모 실행 방법을 포함한다.
- M1은 작은 기존 월드에서 안정화하고 렌더링 구조 변경은 M2에서 진행한다.
- 지형·건축물은 청크별 노출 면을 묶고, 반복 장식물은 인스턴싱을 활용하는 방향으로 검토한다.
- M2 시작 시 대상 PC, 테스트 월드 크기, 목표 FPS를 정한다. 아직 성능 수치는 확정하지 않았다.
- 기존 저장 데이터는 이전하거나 원본을 보존하고 복구 방법을 제공한다.
- 상태는 준비 / 진행 중 / 검증 중 / 완료로 기록한다. 확인하지 않은 항목은 완료로 표시하지 않는다.

## 진행 기록

### 2026-11-14 — 범위 합의 및 코드 사전 검토

- 감성적인 탐험·건축 방향과 M1–M5 범위를 합의했다.
- 프로젝트 소스와 설치된 일부 의존성을 읽었다. 실행·브라우저 재현·빌드 검증은 아직 수행하지 않았다.
- 코드에서 확인한 사항:
  - 저장 데이터를 검증·예외 처리 없이 JSON 파싱한다. 손상된 저장값이 초기화를 막을 가능성이 있다.
  - HUD의 `Array(6).map(...)`은 빈 슬롯을 순회하지 않아 의도한 재질을 생성하지 않는다.
  - HUD가 매 프레임 React 상태를 갱신한다.
  - 이동 계산에 카메라 상하 회전이 포함되고 점프는 접지 대신 수직 속도로 판정한다.
  - 블록별 메시·물리 객체를 사용하며 같은 좌표에 중복 설치할 수 있다.
- 화면이 나오지 않는 직접 원인은 아직 미확정이다. 위 사항은 실제 증상 재현과 구분한다.
- 작업 전부터 `src/index.js` 수정 및 `src/components/Overlay.js` 삭제가 존재했다. 이 변경을 존중한다.
- 이번 기록 시점까지 게임 코드는 수정하지 않았다.
- 다음 작업: M1 화면 오류 재현, 원인 확정, 기본 조작·저장 안정화 및 데모 검증.

### 2026-11-14 — 사용자 피드백: 시선 기준 이동 수정 및 미니맵

- M1 검증에서 시선을 돌린 뒤의 이동을 빠뜨렸다. 정면 이동·반복 입력 검증만으로 기본 조작 안정화를 충분히 확인했다고 판단한 것은 잘못이었다.
- 기존 빌드에서 180도 회전 후 W 입력 시 Z가 10 → 7.699로 감소하는 오류를 재현했다. 기대 동작은 반대 방향인 +Z 이동이다.
- 원인: PointerLockControls는 쿼터니언을 변경하지만 이동 계산은 XYZ Euler의 `rotation.y`를 사용했다. 이 값은 180도 회전 시 다시 0에 가까워져 실제 수평 방향과 달랐다.
- 수정: 카메라의 실제 시선 벡터를 수평면에 투영해 이동 방향을 구한다. 정확히 위·아래를 볼 때는 직전 수평 방향을 유지한다.
- 추가: 북쪽 고정 미니맵, 블록 배치, 위치·방향 화살표와 시야 부채꼴, 시작점, X/Z 좌표. 지형은 블록 변경 시, 플레이어 표시는 초당 10회 갱신한다.
- 검증: 테스트 19개 통과, 프로덕션 빌드 성공. 브라우저에서 4개 방향별 WASD 총 16가지 이동 확인(상하 시선 변화 포함). 미니맵 위치·회전·설치·파괴 반영 확인.
- 이후 조작 검증에는 반드시 시선 회전 후 전진·후진·좌우 이동을 포함한다.
- [수정 후 미니맵 화면](docs/m1-minimap.png)
